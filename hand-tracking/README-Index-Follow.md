# 食指摄像头跟随

当前已接入真实 SDK 的连续位置跟随，**仅食指 MCP 屈伸**，机械手角度范围 0–10°。其他四指不使能，食指侧摆、PIP/DIP 保留接入时目标。整手三维预览仍可运动，不表示整手真机已开放。

## 启动与操作

Windows Python 继续由 uv 管理，SDK 使用已安装的 `rysen_system:latest` 镜像。专用容器仍名为 `rysen_sdk_readonly`（历史名称），当前跟随模式在其中运行独立的原生 C++ 工作进程，没有启动 Explorer 或 ROS 后端，也不安装普通 WSL。

```powershell
& D:\Dev\wslc\hand-tracking\Start-HandIndexFollow.ps1
# 完整停止摄像头、跟随工作进程和专用容器
& D:\Dev\wslc\hand-tracking\Stop-HandIndexFollow.ps1
```

脚本编译并启动工作进程时默认不使能、不运动。打开 <http://127.0.0.1:8090/>：

1. 点击“恢复 / 重新捕获”，举起左手并让食指完整入镜。
2. “开始食指跟随”可点后，点击开始，缓慢屈伸食指。
3. 点击“暂停并失能”结束；下次需要手动重新开始。

人手食指 MCP 的预览角度 0–65° 连续缩放到真机 0–10°，并非 1:1 全范围跟随。命令从实际反馈位置接入，以每秒 6° 限制目标变化；SDK 中食指速度/加速度参数另设为 6°/s、10°/s²，并检查读回。参数值不是已经验证的严格实际物理速度上限，先前单次试验的速度反馈峰值约 9°/s。

页面显示缩放后的控制指令、实际反馈、使能状态和本进程的运动调用次数。该计数仅属于当前工作进程，不包含历史单次试动或其他程序。上方全手模型是识别预览，真正下发只有食指 MCP 的变化。

## 暂停与超时

- 手动暂停、食指识别无效或局部保持、摄像头数据过期时停止更新并请求失能。
- Windows 页面每 200 ms 更新控制心跳，超过 600 ms 不再转发目标。切换到后台页面会主动请求停止；关闭页面后也会因心跳过期退出。
- Linux 工作进程独立检查目标与反馈，超过 250 ms 即停止跟随并失能。Windows/浏览器卡住时不依赖它们继续发送停止指令。
- 每次开始最多 30 秒，随后自动失能；重新出现左手或继续发送目标不会自动重新使能。
- 连接异常、设备故障、其他关节/使能状态异常或超出试验范围会停止。普通“暂停跟随”、左右手切换和“停止服务”也会请求停止真机跟随。

停止会失能，**不会自动回零**；失能后机械姿态可能自然变化。这里没有认证的物理急停能力，故障/断网下硬件停止行为尚未全面实测，按设备既有方式保留物理停止措施。

## 进程、网络与参数

Windows 8090 服务执行识别和映射，通过仅发布到 `127.0.0.1:8092` 的桥接服务向原生 SDK 进程发送目标。桥接控制接口需要本机生成的控制令牌；令牌保存在 Git 忽略的 `profiles/sdk-control-token.txt`，不发送给浏览器。SDK 进程输入只接受 START、STOP 和 0–10° 的目标，不接受任意关节命令。

原生进程退出前先请求失能，再恢复接入前保存的 SDK 速度/加速度参数。SDK 1.4.7 的 Disconnect 还会请求全指失能，因此不要与其他设备控制程序共享连接。启停脚本阻止本项目 Explorer 和 SDK 进程同时使用设备；原 `Start-HandSdkMonitor.ps1` 会先停止跟随进程再切回只读模式。

继续使用原 `Stop-HandMapping.ps1` 或页面停止按钮只结束 Windows 服务，原生 SDK 进程仍会保持连接（失去目标后失能）。完整退出请使用 `Stop-HandIndexFollow.ps1`。不要直接停止 Explorer 容器来代替停止跟随进程。

## 验证与范围

2026-10-18，Windows 39 项测试通过；原生模拟 SDK 7 项摄像头跟随测试通过，覆盖未使能默认启动、手动停止、目标过期、反馈过期、故障、越界目标和输入进程退出。初次启动实际 SDK 时确认五指均未使能、调用次数为零。

用户已确认实际食指可以同向小幅跟随，页面暂停正常。SDK 日志也记录到手动使能/失能以及一轮满 30 秒自动失能。收尾时再次暂停并核对设备状态。约 1° 的到位误差仍按已有试验现象处理，没有添加硬件零位补偿，也没有确认其全部来自硬件。

约束、目标、反馈和跟随状态由现有 `logs/sdk-dry-run.jsonl` 记录（历史文件名，当前也记录真实食指模式）。原生诊断在容器 `/tmp/hand-sdk-follow.log`，不保存摄像头画面。完整整手、拇指、侧摆、抓取和力控仍未开放。
