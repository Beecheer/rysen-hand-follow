# D435 全链路交付与验证

日期：2026-10-20。范围：完成 D435＋MediaPipe 的软件架构、个人标定、解算、控制全链路，交付后由用户做本人标定及实际动作验收。未生成虚假的个人配置，未自动请求机械手运动。

## 最新补充：可选拇指四位置静态标定

已按用户要求加入 `StaticThumbCalibration`，自然展开、向食指根部收拢、向小指方向收拢、朝镜头抬起四步，每步准备 1 秒、静止采样 3 秒，至少 20 有效帧。只使用可靠根部/指尖深度和掌面；拒绝明显转掌、位置波动 P90 超过 6 mm、点间不足 8 mm、三维分布退化及过度放大/压缩的映射。

每步显示并可编辑对应的机械手根部三个参考角；模型显示覆盖与 SDK 目标分离，预览会先确认停止，不发送参考姿态。四个人手位置与模型指尖位置建立仿射对应，实际接入解析位置换算；远超支持范围时平滑退回基础映射。末端 j3/j4 仍固定，不宣称新增了独立末端自由度或机械手角度真值。

单独保存 `d435-articulated-thumb-static.json`，基础 `d435-articulated.json` 不改写。支持保存/加载、备份、重采、取消、启停对比及独立重置，绑定基础骨架/相机/URDF/末端设置/限位，配置变化则停用旧参考。A/B 连续专项继续使用原实现。

**126 项 Python 测试及 5 组前端测试通过**。新增 8 项覆盖：四姿态保存/加载与逐锚点位置对应；静态位置进入实际解析控制链；退化/不稳定/缺深度采样拒绝；基础改变后失效；未确认失能时禁止预览；参考显示不改 mapper；范围外回退；真实 session 的相机观测进入采样。前端测试覆盖四步引导、编辑参考不被状态刷新覆盖、采样互斥、参考显示覆盖和退出恢复。日志 `logs/depth-thumb-static-tests.log`。

尚未替用户采集本人四位置数据，不自动写入真实静态个人配置。默认参考角只是可审阅的几何预设，操作者需按模型检查并采对应姿态。当前实现与操作以 [拇指静态标定说明](../README-ThumbStatic.md) 为准；下文“尚未实现静态标定”属于当时历史状态。

## 2026-10-20 解算抖动修复

用户已完成 D435 八姿态，并报告四指和拇指抖动、偶发大幅抽搐。读取服务确认仍为无 SDK 的预览模式。诊断采到 227 帧数值骨架；当时主映射处于暂停，所以使用同一组骨架、深度观测和当前个人配置离线复算，而没有将暂停输出当成静止性能。

- 原始模型相对骨架逐帧位移 P95 约 5.67 mm，旧融合骨架约 21.05 mm；中指 PIP 单帧解算变化最大约 65.33°，拇指 j0 约 32.56°。这表明融合与逆解放大了输入变化，不能只归因于摄像头识别。
- 深度求解改用上一帧加模型相对运动预测作为初值；时间连续性使用自适应二次约束，不再被全局鲁棒损失降权成“可放过的异常”。同组复算，融合骨架位移 P95 约 7.33 mm，四指不再出现原有的约 65° 翻解。
- D435 四指几何角增加三帧中位确认及运动方向一致性驱动的自适应平滑，主动连续运动加快响应。D435 拇指逆解增加输入变化驱动的局部信赖域与关节连续性正则，防止输入稳定时跳到远处关节解。没有更改 SDK 的速度/加速度、关节限位或碰撞逻辑；旧 A/B 不启用这些新增运行策略。
- 同一段数据的最终解算输出，中指 PIP 最大单帧变化约 3.84°，拇指各关节约 3°。这些是该段数据复算结果；拇指信赖域会随主动输入扩大，不代表任何动作都被固定限为每帧 3°，也不是精度真值。
- 主项目 **98 项测试通过**；共享深度工具 **13 项通过**。新增测试覆盖歧义骨段不翻转、真实屈伸预测仍可通过、静止角噪声抑制与主动响应，以及拇指静止分支稳定和主动运动信赖域扩大。

## 2026-10-20 四指侧摆抽动修正

操作者反馈以四指侧摆为主。数值记录 `logs/depth-finger-twitch.json` 中，旧解算把屈伸引起的图像移动用于放松所有关节的连续性约束；侧摆可观测标志也恒为真。新版为侧摆单独保留连续性约束，并随近节缩短增强；近节遮挡或接近朝向镜头时保持侧摆而继续更新屈伸。保留快速屈伸恢复逻辑，未修改掌面、拇指算法、限位或个人标定。

同一组 260 帧数值观测、约 0.1 秒步长离线回放，相邻帧侧摆变化 P95（食/中/无名/小指）从 6.52/9.76/9.90/11.96 度降到 2.11/1.76/2.45/2.41 度；最大值仍有 7–15 度，不能解释为消除了全部抽动。记录含主动动作，无角度真值；这些指标只衡量输出连续性，不证明准确度或真实延迟。明细见 `logs/depth-finger-sway-comparison.json`，回放近似时序不等同于在线运行。
