# 中立位与四指对指标定

打开 <http://127.0.0.1:8090/>，在“中立位与四指对指标定”面板操作。此功能只驱动三维预览，不连接真机。

## 五个姿态

先确认画面中的实际左手显示 Left。手腕和所有指尖完整入镜，保持舒适的距离和相近掌面朝向，避免对指时拇指尖完全被其他手指挡住。每步先摆好姿态，再点“采集当前姿态”：准备 1 秒，随后保持 2 秒。采样时模型暂停跟随，但摄像头继续识别。

1. **中立位**：四指自然伸直、接近平行，不要刻意扇形张到最大；拇指舒适展开。这个姿态定义四指侧摆零位；不直接扣减 MCP/PIP 屈伸角度。
2. **拇指碰食指尖**：指尖轻触，其他手指自然放松。
3. **拇指碰中指尖**：保持接触，尽量让相机看到两个指尖。
4. **拇指碰无名指尖**：允许目标手指自然弯曲，不要用另一只手掰动。
5. **拇指碰小指尖**：轻触即可，不用把整只手攥成拳头。

每步至少需要 20 个有效帧。程序检查姿态稳定性、关键点完整性、中立位弯曲程度和对指距离；失败会提示原因，可以重采。“取消采样”保留已完成步骤；重采中立位会清除本轮四个对指样本，因为它们依赖中立位零点。

四个对指步骤由你确认确实轻触，视觉距离检查不能证明真实接触。不要用“看起来很近但没接触”的姿态代替，也不要把不同步骤采成同一个姿态。

## 应用与检查

五步完成、拟合通过后，“应用并保存”才会可点。点击后恢复跟随；若丢手暂停，再点击“恢复 / 重新捕获”。依次检查：

- 回到中立位，四指侧摆应接近平行；屈伸继续按关键点计算，可能保留识别偏差。
- 缓慢张开、并拢四指，确认侧摆方向连续。
- 拇指依次触碰四指，观察模型指尖是否接近，以及过渡是否自然。
- 轻微改变掌面朝向再重复；明显跳动时先排除遮挡和深度估计错误。

使用“对比”按钮切换是否启用标定，可观察同一动作的变化。“重置标定”会停用并清除当前草稿，旧配置保留备份。采样过程中不会覆盖已应用的配置。

“指尖目标残差”是求解器中机器人拇指尖到混合目标的距离，单位毫米；它不是摄像头测距精度，也不是两根真实手指的接触误差。残差持续较大意味着目标可能不可达、被关节耦合限制，或本次标定/识别有偏差。多个指尖同时很近时使用连续加权，可能落在指尖之间；这是当前方法的限制。

## 保存内容与适用范围

配置保存到 `D:\Dev\wslc\hand-tracking\profiles\current.json`，下次启动自动加载并启用。保存的是五个姿态的关键点/角度统计、中立位偏置、拇指位置变换和模型/摄像头设置，不保存照片或视频。覆盖与重置时在同目录生成带时间戳的备份，`profiles/` 已被 Git 忽略。

摄像头编号、后端、左右手校正设置或 URDF 变化时，旧配置不会自动使用。更换使用者、明显改变拍摄方式，或发现对指方向持续偏斜时，应重新采样。镜像只改变显示，无需重标。

四指当前只校正侧摆零位，屈伸保持标定前的计算，不扣减中立位 MCP/PIP，不拟合角度增益；拇指使用五个参考点拟合位置的旋转、平移和统一比例。中立位的机器人拇指参考角为 `[0.45, 0.20, 0.30, 0.12]` rad，属于预览参考姿态，不代表人体解剖零位。对指附近再根据当前机器人四指姿态增加指尖接近约束，整个过程仍是连续关键点解算，没有增加动作分类器。

机器人与人手的骨长、关节轴和耦合不同，五点标定不能保证所有对指姿态严格重合，也不包含碰撞检测。当前先检查预览效果，再考虑后续真机映射。

修正版兼容旧版配置：启动时利用已保存的五姿态样本，在内存中重建拇指对应关系，同时停止扣减四指屈伸偏置。无需重采，旧文件不被覆盖。新采样保存为 schema 2。之前直接扣减中立位 MCP/PIP 的做法会压缩弯曲幅度，现已移除；若未来需要屈伸幅度标定，应单独采集充分伸直和弯曲的范围参考，不能用单个中立姿态推断。
