# 掌心朝前：八姿态个人标定（方案 A）

打开 <http://127.0.0.1:8090/>，使用“掌心朝前 · 八姿态个人标定”面板。先在摄像头诊断预览中完成与验证，再考虑实机跟随。采集、应用、切换或重置标定会请求暂停实机跟随；不会自动重新使能。

## 操作顺序

确认实际左手显示 Left，掌心尽量正对摄像头，手腕、掌部和指尖完整入镜。摆好姿态后点击“采集当前姿态”，每步准备 1 秒、采样 3 秒，至少需要 20 个有效帧。采集中模型暂停，人手关键点和结构统计继续更新，机械手拇指逆解暂缓，以减少采样负担。

| 步骤 | 姿态 | 要点与用途 |
|---|---|---|
| 1 | 中立位 | 四指自然伸直、接近平行，拇指舒适展开；建立掌面、个人骨长比例、噪声和侧摆参考 |
| 2 | 四指舒适张开 | 不强撑极限；检查与中立位有足够侧摆变化，不将张开幅度映射成机械手最大范围 |
| 3 | 钩手 | 指根尽量伸展，主要弯指间关节；检查 PIP 可观测的弯曲变化 |
| 4 | 指根轻弯、指间较直 | 从指根轻弯，避免指尖完全指向镜头；检查 MCP 的独立变化 |
| 5–8 | 拇指依次轻触食指、中指、无名指、小指尖 | 保持两个指尖尽量可见，不挤压；建立机械手指尖对应关系 |

不需要摆出精确的 45°、90°。钩手、指根弯曲和张开的检查只验证姿态有足够变化，不把动作名称当成角度真值。对指是否真的轻触由操作者确认，视觉距离不是接触测量。

采样失败可重采；“取消采样”保留已完成步骤。重采中立位会清空本轮其余样本，因为它们依赖中立参考。八步完成且结构、姿态变化、指尖对齐检查通过后，才能“应用并保存”。

## 启用后的行为

- 用个人掌部模板的多点拟合稳定掌面方向；二维掌宽比例和估计法向与中立参考共同用于朝向提示。它是可用性指标，不是精确手掌转角。
- 掌心朝前且近节骨段投影足够长时，侧摆主要参考图像平面方向。图像使用实际宽高换算；屈伸仍依赖三维观测。
- 四指采用固定个人骨长的关节链拟合，结合局部残差、标定噪声和弱时序约束。计算使用解析雅可比和固定少量迭代，不做机械手碰撞求解。
- 人手 DIP/PIP 分别估计，不施加机械手的 1:1 联动。机器人输出仍保留原有联动与限幅。
- 中立位只定义侧摆参考，不扣除 MCP/PIP 弯曲角，不把握拳强制拉满机械手范围。
- 拇指先按个人骨长重建并检查异常骨段，再交给现有机器人四维逆解与对指约束。这里不是完整的人体 CMC 解剖轴辨识。
- 明显偏离掌面参考或侧摆不可观测时，侧摆和拇指可暂保持，仍可更新可靠的四指屈伸。局部骨段拟合不可靠时保持对应手指。长时间丢手、通信与 SDK 故障仍按原机制停止。

“人手估计”显示结构拟合后、侧摆偏置修正前的数据；“输出”是经标定、滤波和机器人限位后的目标。“停用标定”同时停用新个人结构层，回到原始几何解算，以便对比。

## 动态一致性检查

先暂停并失能实机，再恢复摄像头识别。两组检查各 10 秒，结果只在当前服务内存中保留，不写回标定，也不发送运动命令。

1. **张合检查**：缓慢张开—握拳—张开三次。看可用帧比例、MCP/PIP 变化和不希望出现的侧摆串扰。
2. **转掌检查**：保持手形，小幅转掌和平移。看侧摆与屈伸是否被整体运动带偏；明显转侧会触发观测保持，不要把大角度侧掌当作正对约束内的检查。

报告中的角度范围为有效观测的 5–95 百分位变化量。没有独立真值，所以不输出“真实角度精度”或自动宣称标定合格。较低抖动也可能来自局部保持，应结合页面质量提示一起判断。

## 配置兼容与限制

个人配置仍在 `profiles/current.json`。新版为 schema 3，包含八姿态统计、骨长比例、掌面模板、采样噪声和拇指对齐。旧 schema 1/2 仍按原有行为加载；不会猜测缺失的三种姿态，也不会仅因启动就覆盖旧文件。新标定只有点击“应用并保存”时才写入，并将已有文件备份为 `backup-时间戳.json`。重置也保留备份。

更换操作者、摄像头设置、左右手校正或显著改变拍摄方式后应重采。所有“骨长”来自视觉估计的相对比例，不是毫米级人体测量；手指完全遮挡、系统性深度错误仍可能产生合理但不真实的姿态。对指残差只表示机器人求解器的目标拟合误差，不是摄像头精度。
