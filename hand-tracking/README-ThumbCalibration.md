# 拇指专项连续运动标定

在已有八姿态标定上补充拇指自然位和连续轨迹，A/B 独立保存。页面底部“拇指专项 · 连续运动标定”提供入口，可直接打开 `http://127.0.0.1:8090/#thumbCalibrationPanel`。

## 操作

先保证当前识别后端的基础标定已启用。采集、应用和切换专项参考均会请求暂停并失能；服务不会自动恢复实机跟随。采样期间模型保持原输出，摄像头仍在采集。无需每步恢复识别，完成一步后可直接采下一步。

掌心保持朝前，手掌和全部指尖完整入镜，避免用转手腕代替拇指运动。每步准备 2 秒；自然放松保持 4 秒，其余每步采样 12 秒，缓慢完成 2–3 次完整往返。

| 步骤 | 动作 |
| --- | --- |
| 自然放松 | 四指自然展开，拇指舒适放松并保持不动 |
| 沿掌面展开与收回 | 拇指在掌面内展开、向食指侧收回，再展开 |
| 向镜头抬起与回落 | 拇指离开掌面朝向摄像头，再回落，手掌不转动 |
| 末端弯曲与伸直 | 根部尽量不动，弯曲末端两节再伸直，允许自然协同 |
| 碰食指尖后返回 | 从自然展开出发，轻触食指尖，再回到展开 |
| 碰中指尖后返回 | 同上，改为中指 |
| 碰无名指尖后返回 | 同上，改为无名指，可适当弯曲无名指 |
| 碰小指尖后返回 | 同上，改为小指，不勉强撑开或扭掌 |

实际接触由操作者确认；视觉接近只能检查明显错采，不能证明物理接触。自然放松至少 20 帧，动态至少 35 帧；动态还检查该方向范围和两次往返。失败只重采当前步，其他已完成步骤保留。成功重采自然放松会清空这轮其他步骤，因为参考原点已改变。

全部完成后点击“生成、应用并保存”，再点“恢复 / 重新捕获”，先比较静止展开、单独弯曲和四指对指的预览效果。“对比：停用专项参考”可退回原有解算；切换后仍需恢复识别。确认预览后再自行启动实机跟随。

## 解算与文件

- 采样按运动进度生成七个稳健轨迹节点，自然位生成一个节点；不保存画面，不持久化全部逐帧原始数据。
- 节点包含个人骨段方向、标定指尖目标和几何逆解参考。运行时对附近参考连续加权，在逆解目标中增加姿态连续性约束；对指位置仍优先，超出采样支持范围时平滑减弱专项约束。
- 自然位的波动用于设置参考混合宽度。个人舒适范围不被直接拉伸到机械极限；原有设备限位、联动、滤波与通信保护继续生效。
- B 保存为 `profiles/wilor-current-thumb.json`，A 保存为 `profiles/current-thumb.json`；基础配置保持原样。重复应用前自动生成带时间戳的专项备份，写入使用临时文件后替换。下次启动自动加载。
- 专项配置绑定基础标定、后端和摄像头校正上下文。重新应用基础标定后，旧专项参考自动失效，需要重采；不混用 A/B 样本。

这里没有独立测得的机器人角度真值。参考来自现有 URDF、接触约束与有界逆解，可减少冗余自由度的错误补偿，但不能保证绝对角度精度，也不能消除单目深度的缓慢漂移。B 的本人八步采样已于 2026-10-19 保存，共 50 个参考节点；尚未取得操作者对专项标定效果的明确对比结论。离线审查发现部分映射目标不可达，详见 [当前交接记录](docs/STATUS.md)。
