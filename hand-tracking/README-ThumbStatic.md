# D435 拇指四位置静态标定

入口仍为根目录 `Start-DepthFollow.cmd -PreviewOnly`，主页面 http://127.0.0.1:8090/ 。先使用纯预览。现有两步骨架配置继续保留，四指不用重采；A/B 的连续拇指标定保持原样。

## 操作

在页面找到“拇指 · 四位置静态标定”，掌心正对相机，四指自然展开，拇指根部和指尖保持可见。每步准备 1 秒、静止采样 3 秒，至少 20 个有效帧。

1. **自然展开**：拇指舒适展开，作为新的指尖中立位置。
2. **向食指根部收拢**：掌面不转动，拇指向食指根部收拢，保持可见，不要求触碰。
3. **向小指方向收拢**：向小指根部方向舒适收拢，不勉强接触，避免用其他手指盖住指尖。
4. **朝镜头抬起**：保持手掌不转动，将拇指抬离掌面，产生明确的前后深度变化。

每步可先点“查看 / 更新参考姿态”，查看模型对应动作。预设参考角度只是机械手几何参考；可调整 j0/j1/j2，再更新预览，随后保持相应的人手姿态并点“采集当前动作”。调整参考角度会清除该步旧样本。参考姿态只覆盖三维显示，角度表、SDK 目标和实际设备不被替换；页面明确标注“参考预览（不发送）”。

四步完成后点“生成、应用并保存”，再点“恢复 / 重新捕获”，检查拇指空间运动。可用“停用/启用专项参考”对比效果。“取消”退出当前采样或参考预览，已有样本保留；“重置拇指静态标定”只重置这份拇指配置，不改变基础骨架。

## 采样问题

- 有效帧不足：检查指尖、根部及掌面深度，保持相机距离和可见度；页面显示主要拒绝原因。
- 位置不稳定：当前 P90 位置波动需不超过 6 mm，保持静止后重采。
- 位置太接近：四步需要明显不同的位置，任意两点至少约 8 mm。
- 空间区分不足：不要只在掌面内采四个点，重采“朝镜头抬起”；平面内的两个收拢姿态也应有所区别。
- 映射放大/压缩过大：检查采样范围、姿态对应和模型参考角度，重采不合适的步骤。

重采自然展开会清除其他三步。标定姿态属于操作者提供的对应关系，没有额外动作分类器验证每一步语义是否正确。

## 运行与保存

四个指尖相对根部的位置，与四个机械手参考指尖位置建立三维仿射对应，校正方向、尺度及轴间耦合；不是单纯加大角度增益。进入正常跟随后仍使用解析角度换算，不增加迭代逆解。远超采样范围时平滑退回基础位置映射；指尖深度缺失时继续使用近端方向回退。

机械手 j3/j4 仍固定为页面配置角度，静态标定不会恢复独立末端屈伸。参考对应来自用户选择的模型姿态，不是实际关节角度真值，也不能使不可达目标变得可达。

单独保存为 `profiles/d435-articulated-thumb-static.json`，保存和重置保留时间戳备份，不改写 `d435-articulated.json`。文件绑定当前基础骨架、相机/左右手上下文、URDF、拇指设置和软件限位；这些发生变化时停用静态参考并要求重新采集。启动时校验通过则自动加载，仍不会自动启动真实跟随。

参考预览、采样、应用、切换、重置均先请求停止并确认五指失能；不能确认停止时拒绝操作。采样期间不允许修改基础标定或末端设置。只保存位置/角度与统计，不保存画面。
